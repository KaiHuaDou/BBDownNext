# BBDown 外部后处理协议

本文档描述主程序与外部后处理进程之间的文件交换协议。主程序通过 `--post-process <exe>` 注册外部进程，下载完成后把轨道文件交给该进程处理；主程序不感知处理语义，也不内置任何解密能力，是否加密由处理方自行判断。

## 触发条件

配置了 `--post-process` 时，DASH 封装的视频轨 / 音频轨 / 背景音 / 配音轨（`DashDownload` 内对每条轨）下载完成后均触发外部后处理；加密与否由处理方判断（退出码 0 且无产物即表示无需处理）。未配置 `--post-process` 时整个路径不初始化，轨道原样参与混流。FLV 分支与直播录制不经此路径。

## 调用方式

主程序对每条待处理轨道写一份请求 JSON（位于轨道同目录，文件名 `postprocess_<guid>.json`），以该文件路径为唯一参数调起外部进程单次执行：

```
<exe> <请求JSON路径>
```

- 单次执行，进程退出后主程序校验产物，随后请求 JSON 被删除。
- 超时 20 秒，超时后进程被终止并按失败处理。

## 请求 JSON

PascalCase 序列化（与主程序源生成器输出一致），字段如下：

| 字段        | 类型   | 说明                                                |
| ----------- | ------ | --------------------------------------------------- |
| `Aid`       | string | 稿件 av 号（字符串）                                |
| `Cid`       | string | 分 P 的 cid                                         |
| `Kind`      | string | 轨道类型：`video` / `audio` / `background` / `role` |
| `TrackPath` | string | 已下载轨道文件的本地路径                            |
| `DestPath`  | string | 产物路径（主程序约定为 `<TrackPath>.out.mp4`）      |
| `Ffmpeg`    | string | 本次运行解析到的 ffmpeg 路径（供处理方复用）        |

示例：

```json
{
    "Aid": "170001",
    "Cid": "283298412",
    "Kind": "video",
    "TrackPath": "C:\\Downloads\\video.m4s",
    "DestPath": "C:\\Downloads\\video.m4s.out.mp4",
    "Ffmpeg": "C:\\ffmpeg\\bin\\ffmpeg.exe"
}
```

## 产物与退出码

产物即响应：主程序以「进程退出码 + 产物文件是否存在且非空」判定结果。

| 退出码 | 产物（`DestPath`） | 主程序行为                                   |
| ------ | ------------------ | -------------------------------------------- |
| `0`    | 存在且非空         | 处理成功，产物覆盖原轨参与混流               |
| `0`    | 不存在             | 轨道无需处理，原文件照常参与混流             |
| 非 `0` | 任意               | 处理失败，静默保留原文件，原文件照常参与混流 |

其余失败情况（进程不可用 / 超时 / 异常）同样按失败处理，静默保留原文件。处理方可自行约定非 0 退出码的细分原因（主程序仅区分 0 与非 0）。

## 安全边界

- 请求只携带轨道定位与本地路径，**不携带任何加密特征与凭据**。
- 外部进程自行获取所需信息（如重新抓取 playurl、读取凭据文件），主程序不感知其语义。
- 产物校验通过后覆盖原轨，未通过时原文件不被删除。

## 示例插件

主仓库内置最小实现 `Plugins/BBDown.Sample`（同时作为新插件的模板，自带独立构建配置与测试）：读取请求 JSON 后不做处理，以 0 退出且不写产物，演示协议字段访问与「无需处理」语义（构建与使用见其 [README](./Plugins/BBDown.Sample/README.md)）。实际插件应把产物写入 `DestPath` 后以 0 退出，失败时返回非 0。
